# 0016 — The criterion floor is a driver refusal, and the hooks go

Ratified criteria were protected by a Claude Code `PreToolUse` hook, which fires in one harness and is absent in every other — the driver already dispatches Codex workers that never trigger it, and a prime-agent supervisor would carry its own unrelated `beforeToolCall` mechanism. We decided the floor is a verification computed by the `pce` binary at `ensure_driver_plan_version`, the single door every plan-version advance passes through in any harness, and that the hooks are deleted rather than ported once the pre-graph orchestrator they also serve is retired. We chose this over re-implementing the prohibition per harness because the enforcement split already assigns a prohibition that must survive an unchosen harness to the binary, and a floor that depends on who is supervising is not a floor.
