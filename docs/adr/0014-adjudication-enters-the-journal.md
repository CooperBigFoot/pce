# 0014 — Adjudication enters the journal; a sustain is a freeze

A parked spec dispute routes to the human, but the human's ruling had no durable form — the one observed un-park was performed by deleting three journal events, violating the append-only doctrine. We decided the ruling has exactly two doors: an overrule is a typed journal event appended by a human verb, un-parking the package for a fresh uncharged attempt against the same frozen graph, and a sustain has no verb at all — freezing the revised graph at plan version n+1 is itself the ruling, with completed packages carried by journal replay when their definitions are unchanged. We chose this over tooled journal surgery or a fresh journal because the journal is the only admissible proof, and a record that can be rewritten or restarted proves nothing.
