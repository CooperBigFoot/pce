# 0017 — The criteria are the invariant; the packaging is free

A supervising agent must be able to reshape a frozen graph mid-run — an untacklable package is split into two, edges are re-cut — while never acquiring the power to make done easier, and a package-level immutability rule forbids exactly the reshaping that is legitimate. We decided the driver's plan-version advance admits any repartition whose criteria set is preserved byte-identically or extended, with packages free to split, merge, rename, and re-edge, and refuses any advance that changes, removes, or splits an existing criterion; those reach the human, who freezes the revised version themselves. We chose the criteria rather than the packages as the invariant because the criteria are the goal in executable form, so their preservation is the only checkable statement of "the same thing is still being built".
